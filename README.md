# BusGo

Ung dung theo doi tuyen xe buyt - Do an mon Lap trinh tren thiet bi di dong.

## Gioi thieu

BusGo giup nguoi dung:

- Xem danh sach cac tuyen xe buyt.
- Xem thong tin chi tiet cua tung tuyen.
- Xem cac tram dung va lo trinh cua tuyen.
- Tim kiem tuyen xe buyt.
- Xem vi tri cac tram tren ban do.

## Cong nghe

- Flutter
- Dart

## Chay ung dung

```bash
flutter pub get
flutter run
```
